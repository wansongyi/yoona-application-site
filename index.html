04 · Analysis
Analysis framework

Planned components only. This portfolio artifact makes no claims about results, effects, or clinical outcomes.

Outcomes

Satisfaction, mental-health understanding, service experience, and placement-stability measures.

Covariates / stratifiers

Respondent group, evaluation context, timepoint, service exposure, and other prespecified contextual variables.

Descriptive summaries

Counts, valid denominators, distributions, medians or proportions, and item-level missingness.

Reliability / consistency

Item behavior and internal consistency only when scale structure and sample size make the estimate appropriate.

Missing data

Review patterns and reasons, report analysis-specific denominators, and avoid unexamined imputation.

Small-N interpretation

Emphasize uncertainty and effect size, suppress unstable cells, and avoid overinterpreting subgroup estimates.

05 · Assessment
Dataset intake assessment excerpts

Strongest non-sensitive content condensed from the working assessments, with people, comments, schedules, and document metadata removed.

CDC · integration read
  • County-by-day structure with state and county FIPS identifiers.
  • Coverage spans the main mask-mandate period, Apr 2020–Aug 2021.
  • Policy flag and order code are usable; descriptive fields are sparse in places.
  • State-month or county-month aggregation is needed for joins at lower temporal resolution.
OxCGRT · integration read
  • Daily national and subnational policy series with standardized region codes.
  • Wide raw schema includes policy indicators, flags, notes, indexes, and epidemiological fields.
  • National and statewide jurisdiction variants require deliberate filtering.
  • Index and indicator selection must be documented before aggregation or comparison.
MIT Election Lab · integration read
  • Candidate-level election returns require aggregation for political-context measures.
  • State FIPS and postal identifiers support state-level linkage; county files support finer joins.
  • Election observations are periodic, not daily, so temporal carry-forward rules must be explicit.
  • Relevant election-year filters reduce unrelated historical records before integration.

Portfolio-safe excerpt: no collaborator names, email, comments, private links, schedules, or document metadata are included.
